## What it says

- **The hypothesis is not supported on this set.** The imperative Python
  form passes every cell at attempt 1 (9/9). The declarative cocolog form
  passes one cell at attempt 1 and five eventually (1/9, 5/9). It is
  never better than imperative on any task and uses about 116 times the
  tokens and 2.4 times the lines.
- **`topo` is the one task where the declarative form repairs to par.**
  It reaches 3/3 final, but only 1/3 at attempt 1; Python is 3/3 at
  attempt 1 with 88 times fewer tokens. The property checker accepts any
  valid order for both forms.
- **`reach` and `parses` leave the declarative form behind.** `reach`
  passes once in three trials, at the third attempt; `parses` once, at
  the second. Python solves both first time.
- **The token gap is the cocolog guide.** Each declarative call carries
  the repository guide, about 20 000 prompt tokens; the Python calls are
  a few hundred. Even a successful declarative cell costs about 20 000
  tokens, while a whole Python cell costs 419-506.
- **This is a result about this pipeline, not about Prolog or Python.**
  Python is the model's strongest language, cocolog has a task-specific
  guide, the two forms use different generators, and the sample is three
  tasks and three trials. No combined score is computed.

## Defects found and corrected

- **`reach` case 3 was malformed.** It was pre-registered as `3 3` with
  only two edge lines; a program that reads the stated three edges
  consumed the start node and crashed. Both forms failed it, which made
  run A's whole `reach` lane void. The case is now `3 2` (n=3, m=2), and
  the `reach` lane was rerun as run B. `reasoning_schema.pl` now has
  `v2_reasoning_case_ok/2` and the test checks every graph case's header
  against its edge count, so the defect cannot recur.
- **The paired summary assumed the imperative form ran first**, so the
  first run's summary dropped trials whose order was
  `declarative_first` (and all of `reach`). `v2_form_pair_cells/4` now
  finds both forms in either order; the paired table above is recomputed
  from the pair rows. The test pins both orders.

The 3-task, 3-trial result is a pilot, not an estimate. The next decision
is whether to widen the reasoning task set, change the forms (the
declarative form could use a smaller or task-specific guide), or move to
the next suite.
