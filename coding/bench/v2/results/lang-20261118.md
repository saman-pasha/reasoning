## calculator/cocolog recheck after the warning section

Run: `v2-lang-1794961384827`, one cell set (calculator/cocolog, 3 trials),
same model, seed and mode; JSONL `lang-20261118-calc.jsonl`. After the
run above, the skill gained a
"Warnings, before a parser is written" block aimed at what the calculator
cells kept writing: the `0'` token takes exactly one character (write
`0'(` and `0')`; `0')'` and `0'-(` are `Syntax error: Operator expected`),
the arrow follows the condition in `( Cond -> Then ; Else )`, a
one-character atom is not its code, and the three parser traps the section
already described (`skip_spaces(List, List) :- List = [_|_]`, the
`digits/3` collision, the digit collector's no-`Rest = []` ending).

Trials 1 and 2 passed at attempt 1 (about 23 000 tokens each); trial 3
repaired in 2 (47 136). The first two failures before the warnings were

a recursive-descent calculator; the warning block names both forms.

The guide change and `reason_version 1.10.1` were in the working tree,
uncommitted, when this lane ran: the JSONL's `commit` field is `2a47a99`
(the tree without the guide change), and the lane's generator read the
edited guide because the lane reads the file, not the commit.

## Provisioning note

The first attempt at this run produced 36 `fail_generator` cells with 0
tokens: the local cocolog checkout had no `library/curl.so` (its modules
were rebuilt on 2026-11-17 and curl was skipped), so `library(llm)`'s
`llm_chat` died on `curl_post/6` before any request. `sh
modules/curl/build.sh` rebuilt the module and one probe generator call
succeeded; the run above is the one taken afterwards. The failed run's
JSONL was removed from `results/`.

## Confounds, as stated before the run

- Each language uses its **normal generator**, not one common prompt. C
  uses `codegen_c`, Python `codegen_python`, cocolog `codegen_cocolog`,
  and SWI a short direct prompt. The comparison measures language plus
  guide. A different cocolog or SWI prompt is a different experiment.
- **The cocolog guide changed between the two runs** (the transpiling
  section, then the flow-tools section). The 2026-11-17 row is the
  before, this run the after; `lang-cocolog-skill-20261117.md` is an
  earlier cocolog-only rerun with the repository guide before both
  additions.
- Non-C languages get a **10 s case timeout**; C keeps its 3 s.
- Three trials per cell and one model: the table is a pilot.
- Held-out cases are run only after the repair cases pass.
