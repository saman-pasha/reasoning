Controlled English, gzip-compressed, in Python codegen

Does the controlled English note still help when it is sent compressed? One hard task, mvccs_acid, written in Python by claude-sonnet-5-5 at effort low. Three arms in one run, 60 trials each: the requirement alone, the requirement with the controlled English as plain text, and the requirement with the same text as gzip, then base64.

180 cells, 272 generator calls, 1 274 497 tokens and 53 min of cell time: $6.83 at list prices.

The answer

The gzipped note does nothing: 31/60 first programs right, against 30/60 with the requirement alone (p = 0.50).

The gzip arm behaves as the requirement alone does in every measure. No first program decodes the note, and nothing in them shows that the model unpacked it.

Compression does not save tokens.

gzip halves the characters, but base64 is about 1.2 characters a token against English's 2.9. The 1 145-character note cost 959 prompt tokens a call, more than the 903 of the 2 590-character plain text it holds.

The plain-text controlled note did not repeat its earlier result.

34/60 against 30/60 (p = 0.29), where the first test found 37/60 against 25/60 (p = 0.022). The note may help less than the first test showed, or not at all. A third run later found 33/60 against 24/60, and the three runs together 104/180 against 79/180 (Cochran–Mantel–Haenszel one-sided p = 0.0058).

The controlled note, asked again

With the requirement alone the first programs did better in this run than in the first test (30/60 against 25/60, and the text "error" in 36/60 against 27/60), and the controlled note's gain was 4 cells where it was 12. Taken together, not as a test chosen before either run, the two runs give 71/120 against 55/120. A third run, with a test of the three together chosen before it, found 33/60 against 24/60, and the three together 104/180 against 79/180, p = 0.0058: the note helps, by less than the first run showed.

Limits

  • One task, one model, one language; 60 trials an arm.
  • A model given a tool to run code could unpack the note; this run says nothing of that.
  • The model takes no temperature, and the same prompt passes at different rates in different runs, so only arms of one run are compared.
