A complete IR of the requirement

The translator's IR note of mvccs_acid held 5 of the requirement's 14 sentences, never the command table. This page says how a complete IR was made from the controlled English restatement, every sentence of it, and what three tests chosen before the runs found in Python, guided cocolog and SWI-Prolog.

The IR: 64 sentences, 68 IR terms, 20 039 characters, made with no model call. The runs: 200 cells, 376 calls, 5 427 770 tokens, $18.37.

Where it stands

The IR is complete: every sentence of the restatement has its IR.

The old note read 5 of the requirement's 14 sentences. The new one reads all 64 sentences of the controlled restatement, through a second form of it that the translator reads right, line for line. Every one of the 68 readings was read back by hand.

Complete did not mean better. The complete IR helps the first program in no lane.

All three tests, chosen before the runs, fail: guided cocolog 13/20 against 14/20, SWI-Prolog 0/20 against 0/20.

In Python it does great harm: 3/60 first programs right, against 32/60 with the requirement alone.

Nearly every first program skips the error case and prints nothing there. The arm spent 4.4 times the tokens. The test did not ask about this direction, so it is a description (two-sided p = 3 × 10−9).

It costs more everywhere.

The note adds about 5 000 tokens to every call and saves no repair call: +26 % tokens in cocolog, 3.1 times in SWI-Prolog, where fewer programs passed at all within three calls (10/20 against 17/20).

Why the translator did not read the restatement

The restatement is written for the reasoner's grammar, and the translator's lexicon is another. Two things stopped it:

  • Compounds joined by _. The grammar reads latest_version or commit_id as one noun. The translator knows no such word.
  • commit and abort as nouns. The translator reads them only as verbs, so Every commit is atomic. has no reading. The model taught them as nouns, and its rewrites kept them as nouns (A commit is atomic.), so none of those was read either.

The translator form

controlled/mvccs_acid.translator.txt says each line of the restatement again in a form the translator reads, and reads right. ir_complete.pl reads it with the translator alone (no model, no key, every sentence) and writes the note; if any line is not read, it stops and names it. The note is the same at every run.

What the note looks like

Each entry gives the restatement's sentence, its translator form where that differs, and the IR of each sentence of that form. The model gets the note after the requirement.

- "Every transaction that is not active causes an error.", said for the translator as "If a transaction is not active, it causes an error.":

- "Every key that is visible reads as "yes".", said for the translator as "If a key is visible, it reads as yes.":
  - `join(comma,join(w(if,upper),none,s(none,np(det(article,a,w(a,lower)),none,[],w(key,lower),singular),g(is,present,simple,no),[adj([w(visible,lower)])])),s(none,pronoun(third,singular,w(it,lower)),g(reads,present,simple,no),[pp(w(as,lower),np(none,none,[],w(yes,lower),singular))]))`

The note is about 5 000 tokens, against about 700 for the controlled-English note. Each call carries it, so it must save repair calls to pay for itself.

The tests, chosen before the runs

Each run's README was written and pushed before its first cell (commit cbc3c82). Each run has the requirement alone (plain) and the requirement with the complete IR (ir), shuffled together, seed 20261122.

  • Python: 60 trials an arm. The old IR note did not help Python (2/10 against 3/10, and 3/20 against 7/20).
  • Guided cocolog and SWI-Prolog: 20 trials a lane and arm. The old IR note helped both (9/10 against 3/10, and 5/10 against 0/10). The complete IR holds the four sentences on input that broke guided cocolog in the controlled-English note.
  • Hypothesis, in each lane: the complete IR makes the first program right more often than the requirement alone.
  • Test: Fisher's exact test, one-sided (ir greater), on first-attempt passes, one test a lane, each significant if p < 0.05. The report also says whether each passes p < 0.05 / 3 = 0.0167, the limit for three tests together.

How the first programs failed

  • Python, at the error case. 53 of the 57 failing first programs with the complete IR failed the error case, which expects the word error; 56 of the 57 print nothing there. Only 5 of 60 have the text "error", against 33 of 60 with the requirement alone. The note holds the rule, as the controlled-English note does, but as three entries among 64, each under a long logical form. Every long or structured note so far lowered that count (terms 7/20, outline 5/20, concepts 3/20, the old IR 4/20, against 8/20), and the controlled note alone raised it (39/60). The translator form also holds the model's rewrite The program writes only the answers., and an error line may not read as an answer. The runs do not show which of the two does it.
  • Cocolog, at the first case, as always. 6 of 7 failing first programs printed nothing for v (4 of 6 with the requirement alone). The four sentences on input that broke guided cocolog in the controlled note are in the complete IR too, and here they did not.
  • SWI-Prolog, before the first case. No first program passed in either arm: most did not load. The lane's user message is the requirement alone, and its first replies often begin with prose before the code; that decides the first attempt here, not the note.

What this says about the IR: the old note, read from 5 of 14 sentences, helped the two Prolog lanes once and never Python. The complete IR, read from all 64 sentences, helps no lane and harms Python. On this task the model does better with a rule said once in plain or controlled English than with every rule said as a logical form.
